# PT샵 네이버 블로그 매니저

PT샵(피트니스 센터)용 네이버 블로그 SEO 도구입니다. PC에서 실행하는 **로컬 웹앱**으로,
제목만 입력하면 네이버 SEO에 맞춘 블로그 초안을 만들어 네이버 블로그 글쓰기 화면까지 옮겨주고
(발행은 항상 직접 클릭), 등록한 키워드별로 네이버 인기글(블로그+카페) TOP7 중 우리 업체 글이
몇 개인지, 직원 글인지 체험단 글인지를 대시보드에서 한눈에 보여줍니다.

## 🖥️ (컴퓨터 잘 몰라도 OK) 3분 설치 가이드 - Windows

이 프로그램은 인터넷에 떠 있는 사이트가 아니라, **내 컴퓨터 안에 설치해서 쓰는 프로그램**입니다.
그래서 "URL로 바로 접속"은 안 되고, 아래처럼 딱 한 번만 내려받아 설치하면 됩니다.

- 다운로드된 zip 파일을 오른쪽 클릭 → "압축 풀기(모두 추출)"
- 압축을 풀면 `AutoDrama-claude-naver-blog-auto-writer-lbyec3` 같은 **길고 긴 이름의 폴더**가
  생기는데, 이건 정상입니다 (GitHub가 자동으로 붙이는 이름이에요). 문제는 이 안에서 그대로
  설치하면 전체 경로가 너무 길어져서 **Windows가 파일을 못 만드는 오류**가 날 수 있다는 점입니다.
  → **그 안의 `naver_blog_manager` 폴더만 통째로 잘라내기(Cut)** 해서
  **`C:\` 드라이브 바로 밑에 붙여넣어주세요** (최종 경로가 `C:\naver_blog_manager` 처럼 짧아야 합니다).
  그 다음 원래 다운로드/압축 푼 폴더는 지워도 됩니다.

**2) 설치 (딱 1번만)**

  체크박스를 꼭 켜주세요**) → 설치 끝나면 `1_설치하기.bat`을 다시 더블클릭

**3) 실행**

- 이 검은 창을 닫으면 프로그램이 꺼집니다. 쓰는 동안은 그냥 켜두세요.

### 직원 3명이 각자 PC에서 쓰는 경우 (권장 방법)

**각자 자기 PC에 위 1)~3)을 그대로 설치하는 것을 권장합니다.** 이유는:
- 네이버 로그인/글쓰기 자동화는 **그 프로그램이 실행 중인 바로 그 PC의 화면**에서만 동작합니다.
  만약 한 대(예: 원장님 PC)에만 설치하고 나머지 두 분이 인터넷 주소로 접속하는 방식을 쓰면,
  그 두 분이 "네이버로 보내기"를 눌러도 로그인 창/글쓰기 창은 원장님 PC에서 열려버려서 실제로 쓸 수 없습니다.
- 각자 자기 PC에 설치하면, 각자 자기 네이버 계정으로 로그인하고 자기 블로그에 바로 초안을 보낼 수 있습니다.

설치 후 **블로그 관리** 화면에서:
- 내 PC에는 **내 블로그**를 "공식 블로그"로 등록 (글쓰기 자동화가 여기로 전송됩니다)
- **동료들의 블로그(각자 2개씩 있어도 전부)** 도 "직원"으로 등록해두면, 대시보드에서 "이 순위 글이 누구 것인지"까지
  한눈에 보입니다. 체험단/서포터즈 블로그도 마찬가지로 등록하면 됩니다.

키워드도 각자 PC에 동일하게 등록해두면(예: "서상동PT" 등), 3대 PC 모두 똑같은 방식으로 순위를 보여줍니다.
(참고: 순위 정보는 네이버 공개 검색결과를 그때그때 조회하는 것이라 3대에 각각 등록해도 결과는 동일하게 나옵니다.)

## 주요 기능

1. **AI 블로그 초안 작성**: 제목 입력 → OpenAI가 네이버 SEO 규칙(키워드 반복, 소제목, 글자수,
   해시태그)에 맞춰 초안 생성 → 미리보기/수정 → "네이버로 보내기"로 네이버 블로그 글쓰기
   화면에 제목/본문을 자동으로 채워넣음. **발행은 항상 사용자가 직접 클릭합니다.**
2. **키워드 순위 추적**: 키워드를 등록하면 네이버 통합검색 VIEW(블로그+카페) TOP7을 주기적으로
   조회해, 등록된 블로그(공식/직원/체험단) 중 몇 개가 상위 노출 중인지, 어떤 자리가 누구
   글인지 대시보드 카드에서 바로 확인할 수 있습니다.
3. **이탈 알림**: 이전에는 TOP7 안에 있던 우리 글이 이번 조회에서 사라지면 "이탈 발생" 뱃지로
   표시되고, 카드의 "글 작성" 버튼으로 바로 재작성에 들어갈 수 있습니다.
4. **블로그 등록 관리**: 공식 블로그 / 직원 블로그 / 체험단(서포터즈) 블로그를 등록해두면
   순위 결과의 소유자가 자동으로 판별됩니다.

## 설치

```bash
cd naver_blog_manager
python -m venv .venv
source .venv/bin/activate   # Windows는 .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

`.env.example`을 복사해 `.env`로 만들고 필요시 값을 채워주세요 (OpenAI 키는 실행 후
설정 화면에서 입력해도 됩니다).

```bash
cp .env.example .env
```

## 실행

```bash
python run.py
```

브라우저에서 `http://127.0.0.1:8000` 접속.

최초 실행 시 순서:
1. **설정** 화면에서 업체 프로필 + OpenAI API 키 입력
2. **설정** 화면에서 "네이버 로그인" 클릭 → 실제 브라우저 창이 뜨면 직접 로그인 (아이디/비밀번호는
   저장하지 않고, 로그인 세션만 저장됩니다)
3. **블로그 관리**에서 공식 블로그(필수, 글쓰기 대상), 직원/체험단 블로그를 등록
4. **대시보드**에서 모니터링할 키워드 추가 → "전체 순위 갱신"으로 첫 조회 실행
5. **글쓰기**에서 제목 입력 → AI 초안 생성 → 검토 후 "네이버로 보내기" → 네이버 창에서 직접 발행

## 알아두어야 할 점 (중요)

- **발행은 항상 사용자가 직접** 합니다. 이 프로그램은 네이버 블로그 글쓰기 화면에 제목/본문을
  채워넣는 것까지만 자동화합니다 (네이버에 블로그 발행용 공개 API가 없기 때문입니다).
- **네이버 로그인은 아이디/비밀번호를 자동 입력하지 않습니다.** 실제 브라우저 창이 뜨면 직접
  로그인해야 하며, 로그인 세션(쿠키)만 `data/naver_state.json`에 저장해 재사용합니다. 이 파일은
  기기 밖으로 유출되지 않게 주의하세요 (git에도 포함되지 않도록 이미 제외되어 있습니다).
- **네이버 로그인/글쓰기 자동화는 화면이 있는 내 PC에서 실행해야 합니다** (headless 서버에서는
  로그인 창이 뜨지 않아 동작하지 않습니다). 순위 조회는 headless로 동작하므로 서버로 돌려도
  됩니다.
- **순위 조회 자동화 선택자가 깨질 수 있습니다.** 네이버는 검색결과/에디터 HTML 구조를 예고 없이
  바꿉니다. 순위가 이상하게 나오거나(0개만 잡히는 등) 글쓰기 자동 입력이 실패하면:
  - 순위 조회: `app/services/naver_rank.py` 상단의 `MAIN_CONTAINER_SELECTORS` /
    `EXCLUDE_SELECTORS`
  - 글쓰기 자동화: `app/services/naver_browser.py` 상단의 `EDITOR_IFRAME_SELECTOR` /
    `TITLE_SELECTOR` / `BODY_SELECTOR`
  만 실제 페이지 구조에 맞게 수정하면 됩니다. 자동 입력이 실패해도 브라우저 창은 열린 채로
  남으므로, "글쓰기" 화면의 "복사하기" 버튼으로 내용을 복사해 직접 붙여넣을 수 있습니다.
- **순위 조회는 과도하게 자주 돌리지 않도록 설계되어 있습니다.** 기본 자동 체크 주기는 24시간이고
  (설정 화면에서 변경 가능), 여러 키워드를 조회할 때는 요청 사이에 3~8초 랜덤 딜레이를 둡니다.
  "전체 순위 갱신" 버튼도 필요할 때만 눌러주세요.

## 프로젝트 구조

```
naver_blog_manager/
├── run.py                  # 서버 실행 진입점
├── app/
│   ├── main.py               # FastAPI 앱 조립
│   ├── config.py             # 환경설정
│   ├── db.py / models.py / schemas.py
│   ├── routers/               # API + 페이지 라우터
│   ├── services/
│   │   ├── matcher.py          # URL → 블로그ID 추출 + 소유자 매칭
│   │   ├── naver_rank.py       # 네이버 VIEW 검색결과 조회/파싱
│   │   ├── rank_service.py     # 순위 조회 결과 DB 저장 + 이탈(Alert) 감지
│   │   ├── naver_browser.py    # 네이버 로그인/글쓰기 자동화 (Playwright)
│   │   ├── openai_writer.py    # OpenAI 기반 SEO 초안 생성
│   │   ├── dashboard_service.py# 대시보드 집계 로직
│   │   └── scheduler.py        # 주기적 순위 체크 스케줄러
│   ├── templates/              # 대시보드/글쓰기/블로그관리/설정 화면
│   └── static/                 # CSS/JS (외부 CDN 없이 완전 자체 포함)
├── data/                    # SQLite DB + 네이버 로그인 세션 (git 제외)
└── tests/                   # 유닛/통합 테스트
```

## 테스트

```bash
pytest tests
```

네이버 실제 로그인/검색결과, OpenAI 실제 호출은 자동 테스트 범위 밖입니다(외부 서비스 의존).
순수 로직(URL 매칭, 순위 파싱, 이탈 감지, SEO 체크)과 API 라우트는 유닛/통합 테스트로 검증됩니다.
